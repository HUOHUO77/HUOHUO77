## 📖 项目简介
本项目聚焦**四川广元蜀道文化与女皇文化**，打造一站式智慧旅游服务平台。整合人工智能、电子地图、电商、社交社区等能力，面向游客、景区运营方设计，实现景区数字化、服务智能化。

项目适用于：课程设计、毕业设计、地方文旅小型数字化落地演示，整体架构轻量化、易部署、易二次开发。

### 核心价值
1. 为游客提供智能问答、路线规划、景点讲解、特产购买、游记分享全流程服务
2. 为运营方提供基础后台管理能力，统一管理景点、商品、用户及社区内容
3. 结合地域特色文化，打造本地化智慧文旅解决方案

## ✨ 核心功能模块
### 1. AI 智能导游
- 智能问答：解答景点介绍、游玩攻略、交通食宿等问题
- 语义识别：针对文旅场景优化对话逻辑

### 2. 智慧地图导览
- 广元全域景区点位展示
- 景点详情、开放时间、票价查询
- 游玩路线推荐

### 3. 特色特产商城
- 广元本地特产展示、分类检索
- 商品详情、购物车、订单管理
- 基础订单状态流转

### 4. 旅游社区
- 用户游记发布、浏览、收藏
- 内容列表、动态展示
- 个人作品管理

### 5. 用户中心
- 账号注册、登录、密码管理
- 个人信息编辑、收藏夹、订单查询

### 6. 后台管理系统
- 用户管理、景点管理、商品管理
- 社区内容审核、基础数据配置

## 🛠 技术栈
### 前端
- 核心框架：Vue 2 / Vue 3
- 路由管理：Vue Router
- 状态管理：Vuex
- 网络请求：Axios
- UI 组件库：Element UI
- 第三方能力：地图API

### 后端
- 服务框架：Python Flask
- 数据库：MySQL 关系型数据库
- 缓存中间件：Redis
- 身份认证：JWT 令牌鉴权
- 跨域处理：Flask-CORS
- ORM：Flask-SQLAlchemy

### 工具 & 依赖
- 数据连接：pymysql
- 密码加密、请求校验、全局异常捕获
- 日志记录、参数合法性校验

## 🚀 快速部署 & 运行
### 一、前置准备
1. 本地安装并启动 MySQL、Redis 服务
2. 创建数据库：`guangyuan_travel`
3. 导入项目提供的数据库脚本（`sql/travel.sql`）

### 二、克隆项目
```bash
git clone https://github.com/HUOHUO77/HUOHUO77.git
cd HUOHUO77
```

### 三、后端部署运行
1. 安装Python依赖
```bash
pip install -r requirements.txt
```

2. 修改配置文件 `config.py`
```python
# 数据库配置
MYSQL_HOST = "127.0.0.1"
MYSQL_PORT = 3306
MYSQL_USER = "root"
MYSQL_PASSWORD = "你的数据库密码"
MYSQL_DATABASE = "guangyuan_travel"

# Redis配置
REDIS_HOST = "127.0.0.1"
REDIS_PORT = 6379

# JWT密钥（自行修改为随机字符串）
SECRET_KEY = "your_custom_secret_key"
```

3. 启动后端服务
```bash
python app.py
```
> 后端默认运行地址：`http://127.0.0.1:5000`

### 四、前端部署运行
1. 进入前端目录
```bash
cd frontend
```

2. 安装前端依赖
```bash
npm install
```

3. 启动开发环境
```bash
npm run serve
```
> 前端默认访问地址：`http://127.0.0.1:8080`

### 五、正式打包部署（生产环境）
```bash
npm run build
```
打包完成后，将 `dist` 目录文件部署至 Nginx / Web 服务器。

## 🔐 安全与稳定性设计
1. **身份认证**
   采用 JWT 无状态令牌实现登录鉴权，令牌设置过期时间，保障接口访问安全。
2. **数据安全**
   用户密码加密存储，禁止明文保存；所有前端传入参数统一校验。
3. **异常处理**
   全局统一异常捕获，区分业务异常与服务器异常，友好返回错误信息。
4. **访问限制**
   接口跨域统一配置，基础防重复提交、非法参数拦截。
5. **日志记录**
   关键操作、错误信息日志留存，便于问题排查。
