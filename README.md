# 蜀道智慧广元旅游系统
🔥 广元文旅数字化一站式服务平台

## 项目介绍
蜀道智慧广元旅游系统是面向广元地区的智慧旅游展示平台，融合蜀道文化、女皇文化，为游客提供景点导览、AI问答、地图导航、旅游攻略、社区互动、特产商城等一体化服务。

## 技术栈
- 前端：HTML5、CSS3、JavaScript
- 地图服务：高德地图 API
- AI 问答：DeepSeek 大模型
- 数据存储：LocalStorage 本地存储
- 第三方接口：美团购票、语音播报

## 核心功能
✅ 蜀道揽胜：景点展示、图文介绍
✅ 智慧导览：实时定位、路线规划
✅ AI 智能问答：智能导游、问题解答
✅ 互助社区：游客交流、评论点赞
✅ 女皇御礼：特产商城、购物功能
✅ 行程规划：旅游路线推荐
✅ 实时天气、无障碍模式、多语言支持
