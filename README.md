# 蜀道智慧广元旅游系统
广元文旅数字化解决方案 | AI 问答 + 智慧导览 + 特产商城 + 旅游社区

## 📌 项目介绍
本项目是面向**四川广元蜀道文化**的智慧旅游平台，整合 AI 智能问答、地图导览、文旅商城、用户社区为一体，为游客提供一站式旅游服务。

适用场景：
- 景区数字化升级
- 毕业设计 / 课程设计
- 地方文旅小程序 / Web 平台

## ✨ 功能模块
- ✅ AI 智能导游问答
- ✅ 景区地图实时导览
- ✅ 特产商城 / 订单管理
- ✅ 用户社区 / 游记发布
- ✅ 个人中心 / 收藏管理
- ✅ 后台管理系统

## 🛠 技术栈
**前端**
- Vue2 / Vue3
- Vue Router + Vuex
- Axios
- Element UI

**后端**
- Python Flask
- MySQL
- Redis 缓存
- JWT 身份验证

**第三方服务**
- 地图 API
- AI 大模型接口
