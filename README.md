# 蜀道智慧广元旅游系统
基于 Vue3 + Flask + MySQL + Redis + AI智能问答 的一站式智慧文旅平台

## 🍓 项目简介
本项目是针对广元市打造的区域级智慧旅游系统，集景点导览、AI智能问答、语音讲解、在线购票、用户社区、旅游攻略于一体，实现“吃住行游购娱”全覆盖。

## 🏆 项目亮点
- 🗺️ 智慧地图导览 + 景点推荐路线
- 🤖 AI智能问答助手
- 🎙️ 景点语音自动讲解
- 🛒 在线门票预订与订单管理
- 👤 用户系统 + 评论社区
- 📊 后台管理系统

## 🔧 技术栈
- 前端：Vue3 + Vite + Element Plus
- 后端：Python Flask
- 数据库：MySQL + Redis
- AI服务：百度智能云API
- 地图服务：百度地图

## 🚀 快速启动
### 1. 克隆项目
git clone https://github.com/HUOHUO77/HUOHUO77.git
cd HUOHUO77

### 2. 启动后端
cd backend
pip install -r requirements.txt
python app.py

### 3. 启动前端
cd frontend
npm install
npm run dev

### 4. 导入数据库
执行 sql/init.sql
