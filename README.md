# 蜀道智慧广元旅游系统
## 项目简介
蜀道智慧广元旅游系统是面向广元文旅数字化升级的一站式智慧旅游平台，融合蜀道文化、女皇文化，集成AI智能问答、智慧地图导览、互助社区、特产商城四大核心功能，为游客提供行前、行中、行后全流程服务，助力景区管理增效、城市品牌提升。

## 技术栈
- 前端：HTML5、CSS3、JavaScript、Vue.js
- 后端：Python（Flask）
- 数据库：MySQL、Redis
- 第三方服务：DeepSeek AI、高德地图API、百度TTS、美团购票接口

## 核心功能
1. **蜀道揽胜**：全景展示剑门关、翠云廊、皇泽寺等核心景区，含详细攻略与购票入口。
2. **智慧导览**：高德地图实时定位、路线规划、景点导航、天气查询、语音讲解。
3. **问答社区**：游客经验分享、路线问答、结伴同行、图片发布、互动点赞评论。
4. **女皇御礼**：广元特产商城，支持在线购买、直邮到家。
5. **AI智能问答**：DeepSeek大模型提供景点、天气、路线、文化咨询，支持本地降级回答。

## 项目亮点
- 本地化文化深度融合，蜀道+女皇IP沉浸式体验
- 全链路服务闭环，一站式解决游客旅游需求
- 云端AI+本地双引擎，高可用稳定服务
- 轻量化Web端，无需安装、跨端适配
- 数据持久化，收藏/历史/用户信息云端同步

## 运行方式
1. 打开浏览器访问项目地址
2. 首页：行程规划、热门路线、文旅数据
3. 蜀道揽胜：浏览景点详情、查看攻略、购票
4. 智慧导览：地图定位、导航、语音讲解
5. 问答社区：发帖、评论、互动
6. 女皇御礼：选购特产、下单购买
