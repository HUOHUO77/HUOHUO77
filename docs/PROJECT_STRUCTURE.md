# 项目架构文档 structure.md

## 一、整体架构
本项目采用 **前后端分离架构**
- 前端：Flutter + Riverpod + GoRouter + Dio
- 后端：Python Flask
- 数据库：MySQL + Redis
- 第三方服务：DeepSeek AI、高德地图、百度TTS、美团购票接口

整体分层：表现层 → 业务层 → 网络层 → 数据持久层 → 服务接口层

## 二、前端架构设计（本人负责部分）
### 1. 状态管理架构：Riverpod
摒弃传统 StatefulWidget 局部刷新模式，采用 Riverpod 全局状态管理。
- 统一管理用户状态、景点数据、收藏状态、全局配置
- 跨页面数据共享、状态统一刷新
- 解耦 UI 与业务逻辑，代码可维护性极高

### 2. 路由架构：GoRouter
使用官方推荐 GoRouter 进行全局路由管理
- 统一路由表管理所有页面
- 支持路由拦截、参数传递、嵌套路由
- 规范页面跳转逻辑，避免路由混乱

### 3. 网络架构：Dio 封装
- 统一请求头、超时、拦截器、错误处理
- 统一响应体解析
- 全局 loading、异常弹窗统一管理

### 4. 数据持久化架构
实现三层数据存储：
- 内存状态（Riverpod）
- 本地持久化（缓存用户、收藏、历史）
- 云端数据库同步

## 三、功能架构
1. 蜀道揽胜景点展示模块
2. 高德智慧地图导览模块
3. AI智能问答模块
4. 文旅社区互动模块
5. 特产商城购票模块

## 四、架构优势
1. 架构清晰、分层明确、符合工程化标准
2. 状态统一、路由规范、网络稳定
3. 支持后续迭代扩展
4. 本地+云端双备份，稳定性强
