# 蜀道智慧广元旅游系统 — 项目结构说明

## 一、项目整体结构
本项目采用纯前端轻量化架构，所有功能集成于单一页面，通过模块化、组件化思想实现逻辑分离，便于维护、扩展与部署。

## 二、根目录文件说明
- index.html  
  项目主入口文件，包含完整页面结构、样式、交互逻辑、AI问答、智慧地图导览、社区功能、商城模块等所有核心功能实现。

- README.md  
  项目整体说明文档，包含项目介绍、技术栈、功能列表、运行方式、在线演示地址。

- LICENSE  
  MIT 开源协议，声明项目开源使用条款。

- .env  
  环境配置文件，存储第三方 API 密钥、数据库配置、地图密钥等信息。

- requirements.txt  
  Python 环境依赖清单，用于后端服务环境快速搭建（演示用）。

- CHANGELOG.md  
  项目版本更新日志，记录功能迭代与优化记录。

- CONTRIBUTING.md  
  贡献指南，规范代码提交、分支管理、协作流程。

- report.md  
  项目完整研究报告，包含引言、文献综述、开发过程、测试、结论等。

## 三、文件夹结构说明
- css/  
  存放项目样式文件，负责页面布局、色彩、动画、响应式适配等外观展示。

- js/  
  存放公共脚本与工具函数，负责交互逻辑、事件处理、组件复用等功能。

- docs/  
  项目文档目录，包含结构说明、接口文档、技术报告等扩展资料。

## 四、核心功能模块说明
1. 页面展示模块：首页、蜀道揽胜、智慧导览、问答社区、女皇御礼五大页面。
2. 智慧导览模块：基于高德地图 API，实现定位、导航、景点标注、天气查询。
3. AI 问答模块：对接 DeepSeek 大模型，提供旅游咨询、景点讲解、路线推荐。
4. 社区互动模块：发帖、评论、点赞、图片上传、资料设置。
5. 特产商城模块：商品展示、分类筛选、加入购物车、模拟购买。
6. 数据持久化：用户信息、收藏、历史记录本地存储。

## 五、技术架构特点
1. 前后端分离思想，纯前端实现，部署简单、跨平台兼容。
2. 单页应用模式，页面切换流畅，用户体验佳。
3. 第三方服务模块化接入，便于维护与替换。
4. 响应式布局，支持手机、平板、电脑多端访问。
